# Testing Manual | Evaluación de Calidad Web - E-commerce (Alibaba)

Proyecto práctico de **QA Manual y Testing de aplicaciones web**, enfocado en la evaluación de diferentes componentes de una plataforma de comercio electrónico: Alibaba.

El trabajo consistió en analizar distintos aspectos del sitio, incluyendo navegación, rendimiento, validación del código y diseño de interfaz, con el objetivo de identificar posibles errores y oportunidades de mejora.

## Objetivo y enfoque

Evaluar diferentes componentes de la plataforma mediante pruebas manuales y herramientas de análisis web, considerando tanto aspectos funcionales como técnicos y visuales.

El propósito fue identificar posibles problemas de navegación, rendimiento, estructura y presentación de los elementos de la interfaz, documentando las observaciones obtenidas durante el proceso.

**Características del proyecto:**

| Aspecto | Descripción |
|---|---|
| Plataforma evaluada | Alibaba |
| Tipo de proyecto | QA Manual y evaluación de calidad web |

| Metodología de trabajo | Organización mediante metodologías ágiles |

## Áreas de evaluación y actividades realizadas

### 1. Integridad de enlaces y navegación

Verificación de enlaces presentes en el sitio web para identificar posibles problemas de navegación.

- Revisión de enlaces internos y externos.
- Identificación de enlaces que podrían presentar errores.
- Evaluación de la navegación entre diferentes secciones.

### 2. Rendimiento web

Análisis del rendimiento de páginas mediante herramientas de evaluación web.

- Revisión de aspectos relacionados con la velocidad de carga.
- Identificación de posibles oportunidades de optimización.
- Evaluación de elementos que pueden influir en el rendimiento.

### 3. Validación de código web

Evaluación de la estructura y el marcado de una página mediante herramientas de validación.

- Verificación de la estructura HTML.
- Identificación de posibles errores de marcado.
- Análisis de advertencias y oportunidades de mejora.

### 4. Pruebas de diseño e interfaz

Inspección de diferentes elementos visuales de la plataforma.

- Evaluación de tipografías y colores.
- Revisión de alineaciones y espaciados.
- Análisis de la consistencia visual.
- Observación de aspectos relacionados con la usabilidad.

### 5. Organización y metodología de trabajo

Aplicación de conceptos de metodologías ágiles para organizar las actividades del proyecto.

- Organización y seguimiento de tareas.
- Distribución de actividades.
- Documentación del trabajo realizado.
- Identificación y organización de hallazgos.

## Aprendizajes y conclusiones

Este proyecto permitió ampliar mi comprensión sobre la evaluación de calidad de aplicaciones web, trabajando sobre diferentes aspectos que influyen en su funcionamiento y experiencia de usuario.

Entre los principales aprendizajes se destacan:

- **Visión integral de calidad:** comprender que la evaluación de una aplicación web contempla diferentes aspectos, más allá de su funcionalidad.
- **Análisis técnico:** utilización de herramientas para verificar enlaces, rendimiento y estructura del código.
- **Evaluación visual:** importancia de analizar la consistencia de la interfaz y la presentación de sus componentes.
- **Organización del trabajo:** aplicación de conceptos ágiles para estructurar y documentar las actividades.

La práctica permitió desarrollar habilidades de observación, análisis y documentación, incorporando diferentes enfoques de evaluación dentro del proceso de QA Manual.
