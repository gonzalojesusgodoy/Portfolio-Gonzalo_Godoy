# Metodología Ágil — Coderhouse

Este espacio reúne los contenidos, ejercicios y proyectos realizados durante mi formación en el curso "Metodologías Ágiles" de Coderhouse.

El objetivo es documentar lo aprendido y, principalmente, mostrar cómo estos conceptos pueden aplicarse de forma práctica a la organización, seguimiento y mejora de un proyecto.

## Contenidos

### Fundamentos de Metodología Ágil

Conceptos principales relacionados con las metodologías ágiles y las formas de organizar el trabajo.

- Principios y fundamentos ágiles
- Scrum
- Kanban
- Trabajo iterativo
- Flujo de trabajo
- Organización del equipo

### Product Backlog

Organización y priorización del trabajo que forma parte de un proyecto.

- Historias de usuario
- Tareas
- Priorización
- Valor de negocio
- Riesgos
- Dependencias

### Planificación e Iteraciones

Definición de los objetivos y selección del trabajo que se realizará durante una iteración.

- Planificación
- Selección de tareas
- Objetivos de iteración
- Seguimiento del trabajo
- Resultados esperados

### Gestión Visual

Uso de tableros para representar el estado de las tareas y facilitar el seguimiento del trabajo.

- Tableros Kanban
- Estados de las tareas
- To Do / Doing / Done
- WIP (Work In Progress)
- Flujo de trabajo

### Métricas

Utilización de métricas para observar y analizar el comportamiento del flujo de trabajo.

- Cycle Time
- Lead Time
- Throughput
- Análisis de resultados
- Identificación de demoras y puntos de mejora

### Mejora Continua

Análisis de los problemas encontrados durante el trabajo y definición de acciones para mejorar el proceso.

- Identificación de problemas
- Análisis de causas
- Hallazgos
- Propuestas de mejora
- Seguimiento de resultados

## Proyecto Final

Como integración de los conceptos trabajados, se desarrolló un proyecto práctico en el que se aplicaron diferentes herramientas y conceptos de metodología ágil.

El proyecto incluye:

- Product Backlog
- Priorización de tareas
- Planificación de una iteración
- Tablero de trabajo
- Gestión del WIP
- Análisis mediante métricas
- Identificación de problemas
- Plan de mejora
- Conclusiones

## Objetivo

Utilizar este repositorio como registro del aprendizaje y como evidencia de la aplicación práctica de metodologías ágiles.

La intención es seguir incorporando ejercicios y proyectos a medida que avance en mi formación, relacionando estos conocimientos con la mejora de procesos y la organización del trabajo.
