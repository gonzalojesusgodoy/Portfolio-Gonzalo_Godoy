# ***Tablero***

Para visualizar y gestionar el trabajo se utilizó **Trello**.

El tablero se organizó mediante cinco columnas:

**Backlog → To Do → In Progress (Doing) → Testing / Review → Done**

### Backlog

Contiene las tareas identificadas que todavía no fueron seleccionadas para su ejecución.

### To Do

Contiene las tareas preparadas para comenzar, pero que todavía no se encuentran en ejecución.

### In Progress (Doing)

Contiene las tareas que se encuentran actualmente en desarrollo.

Se estableció un límite:

**WIP = 2**

El objetivo es evitar comenzar demasiadas tareas simultáneamente y favorecer la finalización de las actividades que ya están en proceso.

### Testing / Review

Contiene las tareas que finalizaron su ejecución y están siendo verificadas antes de considerarse terminadas.

### Done

Contiene las tareas que finalizaron correctamente el proceso y fueron consideradas terminadas.
